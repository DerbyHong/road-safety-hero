# 🚦 馬路小英雄 (Road Safety Hero)

這是一款專為國小中年級設計的**交通安全程式邏輯教育遊戲**。透過益智積木拖放，學童可以學習在馬路上「先觀察、後行動」的關鍵觀念。

## 🌟 遊戲核心特色
- **視覺化程式積木**：採用 `dnd-kit` 實作直覺的拖放介面。
- **動態交通環境**：模擬真實紅綠燈切換（綠燈 -> 閃爍綠燈 -> 紅燈）。
- **驚險衝突反饋**：若操作不當（如闖紅燈或未看路），畫面會出現高速車輛緊急煞車動畫，提供強烈的安全警示。
- **循序漸進關卡**：從基本的綠燈過馬路，到進階的規則判斷與閃爍綠燈應對。

## 🎮 玩法說明
1. **觀察環境**：確認目前的紅綠燈狀態。
2. **排列指令**：使用右側工具箱中的「條件」與「動作」積木進行排列。
3. **安全過關**：點擊「開始執行」，引導小英雄安全抵達馬路對面。

## 🛠 技術棧
- **Frontend**: React 18
- **Build Tool**: Vite
- **Drag & Drop**: @dnd-kit
- **Styles**: Vanilla CSS (CSS Modules)
